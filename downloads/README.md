# Скачать MyServ 0.1.4 для Windows

[Скачать Windows x64 preview (ZIP)](https://github.com/kusaka626/myserv/raw/refs/heads/main/downloads/myserv-windows-x64-preview.zip)

Распакуйте архив целиком и запустите `MyServ.exe`. Файл `WebView2Loader.dll` должен находиться рядом. Требуются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime.

Это неподписанная предварительная сборка. EXE собран, но запуск на Windows пока не проверен. Это бесплатная тестовая сборка: настройка сервера доступна без оплаты и лицензии. После выбора протокола сразу открывается установка. Аренду VPS вы оплачиваете хостингу отдельно. Подробности — в `START-HERE.txt` внутри архива и [отчёте о проверках](../docs/VALIDATION.md).

Контрольная сумма архива: [SHA256SUMS.txt](SHA256SUMS.txt).

В версии 0.1.1 для подключения нужны только IP, порт, логин и пароль. Ключ сервера запоминается автоматически, ручное сравнение и галочка удалены. Поддержан вход с sudo, ошибки требований VPS показываются понятным текстом.

В версии 0.1.2 временно включён `free-preview`. Установка настоящая: приложение устанавливает Docker, K3s и выбранный протокол, затем выдаёт конфигурацию.

В версии 0.1.3 исправлена установка Docker Buildx для сборки AmneziaWG. При ошибке показываются этап, код и строка установщика. Для повтора на том же VPS выбирайте прежний протокол; сохранённые ключи используются повторно.

В версии 0.1.4 установка пакетов ждёт блокировку dpkg до 10 минут: автоматические обновления Ubuntu больше не вызывают немедленный отказ. Оставьте приложение открытым на время ожидания.
