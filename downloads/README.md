# Скачать MyServ 0.1.1 для Windows

[Скачать Windows x64 preview (ZIP)](https://github.com/kusaka626/myserv/raw/refs/heads/main/downloads/myserv-windows-x64-preview.zip)

Распакуйте архив целиком и запустите `MyServ.exe`. Файл `WebView2Loader.dll` должен находиться рядом. Требуются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime.

Это неподписанная предварительная сборка. EXE собран, но запуск на Windows пока не проверен. Магазин ЮKassa в этой сборке не настроен, поэтому оплата отключена. Подробности — в `START-HERE.txt` внутри архива и [отчёте о проверках](../docs/VALIDATION.md).

Контрольная сумма архива: [SHA256SUMS.txt](SHA256SUMS.txt).

В версии 0.1.1 для подключения нужны только IP, порт, логин и пароль. Ключ сервера запоминается автоматически, ручное сравнение и галочка удалены. Поддержан вход с sudo, ошибки требований VPS показываются понятным текстом.
